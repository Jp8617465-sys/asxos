# arbi working memory — the untrusted scratchpad (ladder 8)

**This layer is advisory only. It may NOT override repo docs, live state, approved lessons,
the risk register, or the newest handoff.** Untrusted-until-reviewed
(`arbi-memory-policy.md`: `asxos-arbi-working-memory`).

**One append-only file per run** — `YYYY-MM-DD-<run_id>.md` — not a single blob (conflict-
free across parallel unattended branches; mirrors `migrations/` + dated handoffs). A dream
(`/arbi-dream`) consolidates these into a candidate; consumed/condensed files move to
`archive/`.

A run file may hold: patterns noticed · questions to investigate · suspected stale
docs/crons · recurring agent mistakes · candidate lessons not yet proven. None of it is
authoritative until it survives a dream + the promotion gate into `../approved-lessons.md`.
