# Session Catchup

Read the project state and brief me before we start working.

Do this:
1. Read the last 10 git commits: `git log --oneline -10`
2. Check current branch and any uncommitted changes: `git status`
3. Read CLAUDE.md for current project context
4. Check .claude/projects/ memory for session state and blockers
5. Scan for any TODO/FIXME in recently changed files

Then summarise concisely:
- **Current branch** and its purpose
- **Last session** — what was done (from commits + memory)
- **Open blockers** — anything flagged in memory or git status
- **Likely next task** — based on branch name, recent work, and sprint state

Do NOT start any work. Just brief me so I can decide what to do next.
