# build — one-file reversible path — `/build`

**This is the fast speed.** No Guilfoyle graph. No red-team. Multi-node work is
`/arbi-mission`; a genuinely parallel programme is a team (`AGENTS.md` §9).

Stay here only for one file, a same-file refactor, or a tiny sequential fix. If the work
grows a second concern mid-flight, stop and re-route rather than widening this one.

1. Look up the hard owner in `.claude/agents/README.md` and dispatch it if the change has
   one — specialised review by default, not only when asked.
2. Edit on a `claude/**` branch. One concern per branch.
3. Targeted pytest node, then `ruff` and `mypy`; risk-tiered review consult per `CLAUDE.md`.
4. `make check` green, then open the PR **ready** with its class and reversal cost.
5. arbi lands it (`AGENTS.md` §8) and watches the first production run that exercises it.
